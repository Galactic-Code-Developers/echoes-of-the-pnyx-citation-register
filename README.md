# Echoes of the Pnyx — Citation Register

**Research companion to _Echoes of the Pnyx: Athenian Democracy and the Making of the American Constitutional Order_**

This repository preserves the structured citation register used to document the book's evidence base. The register records founding-era and closely related references to Athens, Greek political institutions, classical exempla, intermediary texts, rhetorical use, and source-verification status.

## Release

- Version: **1.0.0**
- Records: **48**
- Fields: **11**
- Main file: `data/citation-register.csv`
- Zenodo record: **https://zenodo.org/records/22071579**
- DOI: **10.5281/zenodo.22071579**

The register is a **documentary source inventory, not a statistical sample** of everything Americans thought about Greece. Row counts should not be interpreted as prevalence estimates. Several documents generate more than one analytical record, and the corpus reflects survival, digitization, searchability, and the defined research scope.

## Versioning policy

GitHub is the working/version-control home. Zenodo is the preservation and DOI layer. Each substantive public data release should receive a semantic version (`v1.0.0`, `v1.1.0`, etc.) and a corresponding Zenodo version. Do not overwrite a published Zenodo version; create a new version instead.

## Relationship to the book

The register supports the book's reception-history method by making the documentary path inspectable. It distinguishes evidence found in primary or scholarly documentary editions from interpretive coding and from bounded no-hit searches. It does not claim exhaustive coverage of every surviving eighteenth-century source.
